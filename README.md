# Share to Care - Food Donation Website

Welcome to the **Share to Care** food donation website repository. This project is a work in progress and aims to create an accessible platform for individuals and organizations to contribute to the fight against hunger.

## Project Overview
The Share to Care website is designed to:
- Facilitate food donations from individuals and organizations.
- Provide information about how donations are collected and distributed.
- Encourage volunteering efforts to support the cause.
- Highlight the impact of contributions in combating hunger.

## Current Features
- **Responsive Design**: Ensures the website is accessible on both desktop and mobile devices.
- **Navigation Bar**: Links to key sections such as About Us, Donate, and Contact.
- **Hero Section**: Highlights the mission and encourages immediate action.
- **Information Sections**: Provides details on how the organization operates, volunteering opportunities, and the impact achieved.
- **Footer**: Contains copyright information and closes the website with a clean look.

## Technologies Used
- **HTML**: Structure of the website.
- **CSS**: Styling and layout with a focus on maroon and olive green as primary colors.

## Installation
To run the project locally:
1. Clone the repository:
   ```bash
   git clone https://github.com//JoyvineNaamah/PLP-Project-Final.git
   ```
2. Open the `index.html` file in your browser.
